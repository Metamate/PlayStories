# Credits

## Art
- Farm background, cow, sheep and UI arrows / speaker / back icons: hand drawn for PlayStories.
- Pig, hen, duck, book covers, close/gear/play icons, FX sprites: procedurally drawn **placeholders**
  (`Tools/build_art.py`), meant to be replaced by hand-drawn art.

## Font
- **Fredoka** by Milena Brandão – SIL Open Font License 1.1 (`Assets/PlayStories/Fonts/Fredoka-OFL.txt`).
  A SemiBold static instance was generated from the variable font.
